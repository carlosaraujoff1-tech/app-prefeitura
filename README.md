# SAP Cidadão

App oficial da Prefeitura de Santo Antônio da Platina (PR) para o cidadão: avisos, agenda, serviços, locais e telefones úteis, e solicitações com acompanhamento.

- Documentação técnica: [docs/DOSSIE-TECNICO.md](docs/DOSSIE-TECNICO.md)
- Regras para quem programa (pessoas e IA): [AGENTS.md](AGENTS.md)
- Banco de dados: `supabase/migrations/` (aplicado no Supabase) e testes em `supabase/testes/`

Comandos: `npm ci`, `npx expo start`, `npx tsc --noEmit`, `npx expo lint`.
